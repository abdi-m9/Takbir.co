# Takbir Website

Modern static website for Takbir General Trading Company Limited.

## Preview locally

```bash
cd web
python -m http.server 5500
```

Open http://127.0.0.1:5500

## Files (flat in `web/`)

- `index.html` - Home
- `about.html` - About and leadership
- `services.html` - Services
- `projects.html` - Project register and gallery
- `contact.html` - Contact (opens email app)
- `styles.css` - Styles
- `main.js` - Interactions
- Image files sit beside the HTML (no subfolders)
